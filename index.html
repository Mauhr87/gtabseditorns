¿Cuál pista de guitarra usar?

Generar bajos desde acordes

Este MusicXML trae acordes y la version actual es fingerstyle melodico. Puedo crear una version nueva con bajos usando la raiz y la quinta de cada acorde.

Guardar arreglo

La cancion puede contener varias versiones. Elige una cancion existente para agregarle esta version, o crea una nueva.

Zona por rango

Aplica una zona preferida de trastes a una seccion. La zona global queda como default para los demas compases.

Crear patron por acorde

Este compas solo tiene notas TAB. Escribe el acorde, o dos acordes separados por espacio si cambian a mitad del compas.

Volver a TAB detallada

Este compas conserva una TAB anterior. Puedes recuperarla intacta o crear una TAB nueva desde el patron que estas viendo.

Comparar versiones

Selecciona las versiones de referencia que quieres ver en paralelo. Podrás copiar compases de ellas a tu arreglo principal.
